# Generalisability of the Interpersonal Theory of Suicide to Latent Profiles of Young People Attending Treatment in a Suicide Prevention Service


This repo contains `R` and `Mplus` code used in the manuscript entitled: *"Generalisability of the Interpersonal Theory of Suicide to Latent Profiles of Young People Attending Treatment in a Suicide Prevention Service."*

Please note, due to privacy restrictions related to the [University of Wollongong](www.uow.edu.au) Human Research Ethics Committee (Ethics Number: HE14/376) approval for this study, no data is available in this repo to reproduce the results reported in the manuscript. However, if you wish to access the data used in this study, an application can be made to the data custodian [Grand Pacific Health](www.gph.org.au).
